# Previdência Premium

PROMPT COMPLETO PARA LOVABLE — JÉSSICA RODRIGUES ADVOCACIA

Crie um mini site profissional, premium, responsivo, elegante e direto ao ponto para Jéssica Rodrigues Advocacia, com foco em Advocacia Previdenciária / INSS.

O site será usado principalmente como link na bio do Instagram, então precisa funcionar perfeitamente no celular, carregar rápido, ter poucas seções bem organizadas e conduzir o visitante rapidamente para o WhatsApp.

MUITO IMPORTANTE SOBRE O DESENVOLVIMENTO

Quero que você gere o projeto completo em uma única execução, evitando refações, componentes desnecessários e complexidade excessiva.

Priorize:

* componentes simples e reutilizáveis;
* uma única página;
* sem backend;
* sem login;
* sem banco de dados;
* sem CMS;
* sem integrações pesadas;
* sem APIs externas desnecessárias;
* sem efeitos complexos;
* sem recursos que aumentem o consumo de créditos;
* usar somente HTML/CSS/React do próprio projeto e bibliotecas já disponíveis.

O objetivo é conseguir um resultado completo e bonito já na primeira geração.
